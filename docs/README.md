## 과거 계획과 비교 실험

- [V3.3 초기 명세](specification.md), [LIRIS 전환 계획](liris-migration-plan.md), [전환 이력](migration_history/)은 단계별 설계 기록입니다. 다운로드·작업 중·다음 단계는 작성 당시의 상태입니다.
- [V3.5.5 파이프라인 설계](decisions/v3.5.5-pipeline-design.md)는 최종 채택 결정과 함께 읽습니다.
- [V3.6 Bandit 실험](decisions/v3.6-bandit-v2-negative.md)은 채택하지 않은 결과입니다. 높은 버전 번호만으로 현재 기본 동작으로 읽지 않습니다.
- `model/autoEQ/train_pseudo/`와 `model/dataset/`의 계획은 초기·비교 경로입니다. 현재 LIRIS 기준 모델과 구분합니다.

## 먼저 이해할 용어

| 용어 | 이 프로젝트에서의 뜻 |
|---|---|
| RIR / xRIR | 방의 소리 전달 특성을 나타내는 임펄스 응답 / 공간 인식 처리 트랙의 이름입니다. |
| EQ | 주파수 대역별 음량을 조절하는 이퀄라이저입니다. |
| Valence / Arousal | 감정의 긍정·부정 정도 / 각성 정도를 나타내는 두 축입니다. |
| CCC | 예측과 정답의 상관·평균·분산 일치를 함께 평가하는 감정 회귀 지표입니다. 오디오 선호율과 다릅니다. |
| Mood / K | 장면의 감정 범주 / 범주의 수입니다. |
| VAD | 음성 활동 구간을 찾는 방법입니다. 감정의 V/A 축과 다른 뜻입니다. |
| Dual-Layer | 대역별 EQ와 추가 효과를 나눈 처리 구성입니다. 대사 구간에서는 효과 강도를 조절합니다. |
| ablation | 특정 구성요소를 바꾸거나 빼서 비교하는 실험입니다. |
| Bandit | 피드백을 받아 선택 정책을 조정하는 방법입니다. 이 저장소의 해당 실험은 채택하지 않았습니다. |
| MUSHRA / A/B 청취 | 여러 처리 음원을 평가하는 절차 / 두 음원을 비교하는 절차입니다. 감정 모델의 학습 성능과 구분합니다. |

## 해석 기준

외부 체크포인트·영상·음원 없이 전체 추론과 평가를 즉시 재현할 수는 없습니다. 자체 코드의 MIT와 외부 모델·데이터의 이용 조건도 구분합니다. 과거 명세의 의도적인 삭제 표시는 변경 이력으로 보존합니다.
